# HeliBoard nopopup &mdash; F-Droid repo

Personal F-Droid repository hosting [HeliBoard nopopup](https://github.com/d33mobile/HeliBoard/tree/nopopup), a personal fork of HeliBoard that suppresses the system spell-check suggestions popup list, leaving only "Add to dictionary" / "Delete".

## Add this repo on your phone

In the F-Droid client: **Settings &rarr; Repositories &rarr; +**, then paste the URL with fingerprint shown on the [landing page](https://d33mobile.github.io/heliboard-nopopup-fdroid/).

The fork has `applicationId = helium314.keyboard.nopopup`, so it installs alongside any existing upstream HeliBoard install.

## Repository contents

The contents of this branch are served via GitHub Pages from the repo root. The actual F-Droid index lives under `repo/`.
