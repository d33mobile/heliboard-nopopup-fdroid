HeliBoard nopopup — F-Droid repo

Personal fork of HeliBoard that strips the system spell-check suggestions popup so it only offers “Add to dictionary” / “Delete” instead of a long list of correction candidates.

Source: github.com/d33mobile/HeliBoard (branch: nopopup)

Add this repo to F-Droid

  1. Install F-Droid client from f-droid.org if you don't have it yet.
  2. In F-Droid: Settings → Repositories → + button.
  3. Paste the URL with fingerprint shown below (long-press to copy).
  4. Update repos, then install “HeliBoard nopopup”.

Repo URL with fingerprint

Use this combined URL in F-Droid — it includes the SHA-256 fingerprint of the repo signing key so the client can verify subsequent updates:

Notes

  • The fork's applicationId is helium314.keyboard.nopopup, so it installs alongside upstream HeliBoard rather than replacing it.
  • After install, switch your IME to “HeliBoard nopopup” in Android Settings → System → Languages & input → On-screen keyboard.
  • Also set the spell checker: Android Settings → Languages & input → Spell checker → pick “HeliBoard nopopup Spell Checker”.
